# Screenshot Demo

This directory defines the generated demo scenario used for documentation screenshots. The actual Rider workspace is generated under `build/screenshot-demo` and is not committed.

All project names, package IDs, and source code are synthetic. Displayed paths point only to the generated demo workspace.

Generate the workspace from the repository root:

```shell
demo/screenshots/generate.sh
```

The captured images are stored under `docs/images/`:

- `source-roots.png`
- `switched-project.png`
- `local-references.png`
- `restored-package.png`
